# System Functions

Welcome to the FaceGuard system function description page. This guide is designed to help you understand how to use the FaceGuard access control system effectively.

## Overview
FaceGuard is a camera-based access control system that replaces traditional physical access cards. It securely identifies registered employees as they approach the entrance and provides immediate access, all while operating completely automatically in the background. It also includes protective measures to prevent spoofing with photos.

## Admin Authentication
To manage the system, administrators must first log in:  
1. Navigate to the FaceGuard web interface on your browser.  
2. Enter your administrator username and password.  
3. Click the login button. Once authenticated, you will have access to employee management and access logs.  

*Note: Make sure to keep your credentials secure, as they provide full control over the entrance permissions.*

## Employee Registration
Adding new employees to the system is quick and easy:  
1. From the admin dashboard, navigate to the **Employee Management** section.  
2. Click on **Add Employee**.  
3. Fill in the employee's details (such as their name and position).  
4. Upload a clear, front-facing photo of the employee.  
5. Save the profile. The system will process the photo and immediately allow the employee to be recognised at the entrance.  

## Employee Management
Administrators have full control over the employee database:

- **View:** See a list of all currently registered employees.  
- **Edit:** Update an employee's details or replace their photo if needed.  
- **Remove:** Revoke access instantly by deleting an employee's profile from the system.  
- **Search:** Quickly find specific employees using the search bar.  

## Face Recognition with LED Feedback
When an employee approaches the entrance, the system automatically begins the recognition process. You will see LED indicators providing real-time feedback:

- 🟡 **Yellow LED:** The system has detected a face and is currently processing the recognition and liveness checks.  
- 🔵 **Blue LED:** Access Granted. The employee has been successfully recognised, and the door is unlocked.  
- 🔴 **Red LED:** Access Denied. The face was not recognised or the liveness check failed (e.g., someone attempting to use a photo).  

## Access Logs
The system keeps a secure record of all entrance activity:

- Administrators can view the **Access Logs** from the dashboard.  
- The logs detail every access attempt, including the time, the outcome (granted or denied), and the identity of the person if recognised.  
- This provides an easy way to monitor building security and track attendance.  

## Background Recognition
The FaceGuard system is designed to run continuously in the background on the entrance hardware. You do not need to keep any specific application window open or manually trigger the camera. As long as the device is powered on, the camera and recognition software are actively monitoring for approaching personnel, ensuring seamless and uninterrupted operation.
